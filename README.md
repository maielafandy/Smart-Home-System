# Smart Home System

## About the Project

This is a simple Smart Home System I built using Python to practice OOP.

The program allows the user to add different devices and control them through a menu.

## Features

- Add a light, fan, or air conditioner.
- View all added devices and their current status.
- Turn devices on and off.
- Change light brightness, fan speed, and air conditioner temperature.

## OOP Concepts

- Classes and Objects
- Inheritance
- Constructors
- `super()`
- Instance Methods
- `isinstance()`

## How to Run

1. Make sure Python is installed.
2. Clone or download the repository.
3. Keep `main.py` and `vaildation.py` in the same folder.
4. Run the following command:

```bash
py main.py
```
